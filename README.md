# Rose Day Special

A creative, visually focused single-page website built with HTML and CSS.  
Designed as a practice project exploring animation, typography, and romantic visual storytelling on the web.

## About

This project was created to experiment with modern CSS techniques, video backgrounds, and elegant layout design.  
It demonstrates attention to visual detail and front-end craftsmanship.

## Features

- Elegant, modern visual design
- Video background support
- Responsive layout
- Custom CSS styling and animations
- Clean semantic HTML

## Tech Stack

- HTML5
- CSS3

## Project Structure

```
├── index.html
├── style.css
├── rose.mp4
└── README.md
```

## How to Run

```bash
git clone https://github.com/ankitsapkota2002-boop/rose-day-special.git
```
